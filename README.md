# LAB 1: Java Maven Starter Project

## Description
This lab exercise demonstrates how to connect a Java application to a MySQL database using JDBC and perform basic CRUD (Create, Read, Update, and Delete) operations on database records.

## Technologies
- Java
- JDBC
- MySQL
- Maven

## Objectives
- Establish a connection between Java and MySQL.
- Execute SQL queries from Java.
- Perform CRUD operations using JDBC.
- Retrieve and manipulate database records.

## Database
- **Database:** `studentdb`
- **Table:** `students`
