# Lab 3 : Spring IoC Lab Setup

## Description
A simple Java project demonstrating the basic concepts of Spring Inversion of Control (IoC) and Dependency Injection (DI).

## Technologies
- Java
- Spring Framework
- Maven
- IntelliJ IDEA

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to download the dependencies.
4. Run the main application class.
