# Lab 2: JPA, Student CRUD Operations

A Java project demonstrating database operations using **Jakarta Persistence (JPA)** and **Hibernate ORM** with a MySQL database.

## Features
- Create new student records
- Update student names and technologies
- Delete students by ID
- Find students by ID
- Retrieve all students
- Search students by technology or by name and technology
- Retrieve students ordered by name in ascending order
- Find the maximum student ID

## Technologies
- Java
- Jakarta Persistence (JPA)
- Hibernate ORM
- MySQL
- Maven

## Configuration
1. Install and start MySQL.
2. Create a database named `jpadb1`.
3. Configure database credentials in `persistence.xml`.
4. Reload the Maven project to download dependencies.

## Run
Run the `App.java` file from your IDE to execute the sample CRUD operations and JPQL queries.
