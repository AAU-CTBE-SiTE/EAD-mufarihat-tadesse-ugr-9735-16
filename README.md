# Lab 7: CRUD Using MySQL

A simple Actor Management REST API developed using Spring Web, Spring Data JPA, and MySQL.

## Endpoints

**Base URL:** `http://localhost:8081/api/v1`

- `GET /actors` – Retrieve all actors
- `GET /actor/{id}` – Retrieve an actor by ID
- `POST /actor` – Add a new actor
- `PUT /actor/{id}` – Update an actor
- `PATCH /actor/{id}` – Update specific actor fields
- `DELETE /actor/{id}` – Delete an actor
