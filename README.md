# Lab 8 : Student API

A simple RESTful API built with **Spring Boot** for managing student records.

### Technologies
- Java 23
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Lombok

### Features
- Create student records
- Retrieve student records
- Update student records
- Delete student records

### Setup
1. Clone the repository.
2. Create a MySQL database named `studentapi`.
3. Configure your database credentials in `application.properties`.
4. Run `StudentapiApplication.java`.
